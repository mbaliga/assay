# Runner decision 1.1.0

The v1 engine is a one-shot Kotlin/JVM process. SSH is transport, not the trust boundary. The runner checks out an immutable source commit in an isolated worktree, runs pinned deterministic tools in an ephemeral sandbox, normalizes and validates artifacts, then publishes with push-with-lease.

Claude Code may be invoked later as a bounded AI adapter with noninteractive structured output and explicit cost/turn limits. It is not the runner and cannot publish findings.

The Dell homelab remains operationally unverified until the same fixture succeeds there without artifact hand-editing. No document or UI may label the Dell path verified before that check.
